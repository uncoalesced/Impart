# Getting help

Impart is not an emergency service. If someone is in danger, call your local emergency number first.

- Setting up phones, pairing, or an alert that did not arrive: read the "First run on a phone" section of `README.md` and the "When it fails" section of `specs/08_FLIGHT_CHECK_PROTOCOL.md`. Most missed alerts come from a battery saver or a full-screen alert permission; the readiness card on the dashboard shows both.
- A bug: open an issue with the bug report template at https://github.com/uncoalesced/Impart/issues. Never post real phone numbers, keys, PINs or locations.
- A security problem: follow `SECURITY.md`. Do not open a public issue.
- Anything else: mail@uncoalesced.com.

This is a small project. Answers can take a few days.
